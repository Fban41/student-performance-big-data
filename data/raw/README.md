# Data Source

**Dataset:** Student Exam Performance & Success Dataset

**Author:** Mobeen Fatima

**Source:** https://www.kaggle.com/datasets/mobeenfatimah/student-exam-performance-and-success-dataset

**License:** CC BY-NC-SA 4.0

**License details:** https://creativecommons.org/licenses/by-nc-sa/4.0/

The dataset contains approximately 100,000 student records and 44 features related to academic performance, study habits, lifestyle and socioeconomic factors.

The original dataset is used for non-commercial educational purposes as part of the Big Data Analytics course at the University of Warsaw.

The raw CSV file has been renamed for consistency. Its contents have not been modified. All data transformations are performed in Databricks.
